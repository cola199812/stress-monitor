## 二、路由和组件结构

### 2.1 路由规划
```
/info-management/products          → 产品列表页
/info-management/products/[id]     → 产品详情页
/info-management/allergens         → 化学应激源列表页
/info-management/allergens/[id]    → 化学应激源详情页
/info-management/symptoms          → 不良反应列表页
/info-management/symptoms/[id]     → 不良反应详情页
```

### 2.2 组件复用
三个模块（产品/化学应激源/不良反应）使用相同的组件模板：
- `EntityList` - 列表页组件
- `EntityDetail` - 详情页容器
- `BasicInfoTab` - 基础信息Tab
- `CollectionTab` - 数据采集Tab

## 三、核心交互流程

### 3.1 侧边栏类别管理流程
```
双击"产品管理" → 展开显示类型列表（化妆品、日化品等） → 
右键点击类型 → 弹出菜单（编辑/删除） → 
选择编辑 → 弹出对话框修改类型名称 → 调用 PUT /entity/categories/{id} → 刷新侧边栏
选择删除 → 确认对话框 → 调用 DELETE /entity/categories/{id} → 刷新侧边栏

点击"+ 新建类型" → 弹出对话框 → 填写类型名称 → 
调用 POST /entity/categories → 刷新侧边栏和筛选下拉框
```

### 3.2 修改产品名称流程
```
列表页点击 ✏️ 修改按钮 → 弹出对话框 → 修改产品名称 → 
调用 PUT /entity/products/{id} → 刷新列表
```

### 3.3 查看佐证数据流程
```
详情页关联表格 → 点击"查看"按钮 → 
调用 GET /relationship/product-symptom/{id}/evidence → 
弹出对话框展示新闻表格（标题、主体关系、发布日期、状态、操作）
```

### 3.4 数据采集流程
```
详情页"数据采集"Tab → 填写采集配置 → 点击"启动采集任务" → 
调用 POST /collection/tasks → 任务开始（状态: pending → running） → 
每5秒轮询任务状态 → 完成后显示结果数量 → 
点击任务卡片 → 查看采集结果表格（标题、AI分类、分类理由、发布时间、操作） → 
勾选数据 → 点击⬇️下载/审核通过 → 调用 POST /collection/results/review → 数据进入正式库
```

## 四、API 调用说明

### 4.1 类别管理（新增）
- `GET /entity/categories` - 获取产品类别列表（二级）
- `POST /entity/categories` - 新建类别
- `PUT /entity/categories/{id}` - 修改类别名称
- `DELETE /entity/categories/{id}` - 删除类别
- `GET /entity/symptoms/level1` - 获取一级症状列表
- `POST /entity/symptoms/level1` - 新建一级症状
- `PUT /entity/symptoms/level1/{id}` - 修改一级症状
- `DELETE /entity/symptoms/level1/{id}` - 删除一级症状

### 4.2 实体管理
- `GET /entity/products/level3` - 获取产品列表（含统计）
- `POST /entity/products` - 新建产品
- `PUT /entity/products/{id}` - 修改产品名称
- `DELETE /entity/products/{id}?level=3` - 删除产品
- `GET /entity/allergens` - 获取化学应激源列表
- `GET /entity/symptoms/level3` - 获取不良反应列表

### 4.3 关联关系
- `GET /relationship/product-symptom?productId={id}` - 获取产品的不良反应关联
- `PUT /relationship/product-symptom/{id}` - 修改关联信息
- `GET /relationship/product-symptom/{id}/evidence` - 获取佐证数据
- `DELETE /relationship/product-symptom/{id}` - 删除关联

### 4.4 数据采集
- `POST /collection/tasks` - 创建采集任务
- `GET /collection/tasks?entityType=product&entityId={id}` - 获取任务列表
- `GET /collection/results?taskId={id}&sourceType=news` - 获取采集结果
- `POST /collection/results/review` - 审核数据

## 五、注意事项

1. **侧边栏双击展开**：产品管理和不良反应导航项支持双击展开，显示下级类别列表
2. **类别管理权限**：右键菜单和筛选下拉框中的类别管理功能需要管理员权限
3. **表格列调整**：列表页表格显示：名称、类型、不良反应数量、化学应激源数量、操作（查看/修改/删除）
4. **佐证数据表格**：参考图片1的样式，显示标题、主体关系、发布日期、状态、操作列
5. **采集结果表格**：参考图片2的样式，去掉"搜索关键字"列，显示标题、AI分类、分类理由、发布时间、操作
6. **采集任务状态轮询**：当有进行中的任务时，每5秒调用一次任务列表接口更新状态
7. **删除前检查关联**：删除实体或类别时，后端会检查是否存在关联关系，前端需要处理 409 错误并提示用户
