## 一、类别管理接口

### 1.1 产品类别管理

---

#### 获取产品类别列表（二级）

```
GET /entity/categories
```

**返回示例**

```json
[
  {
    "id": 5,
    "name": "护肤品",
    "categoryId": 1,
    "categoryName": "化妆品",
    "createdAt": "2025-01-01T00:00:00",
    "updatedAt": "2025-01-01T00:00:00"
  },
  {
    "id": 6,
    "name": "彩妆",
    "categoryId": 1,
    "categoryName": "化妆品",
    "createdAt": "2025-01-01T00:00:00",
    "updatedAt": "2025-01-01T00:00:00"
  }
]
```

---

#### 新建产品类别

```
POST /entity/categories
```

**请求体（JSON）**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | string | 是 | 类别名称，不能重复 |
| category_id | integer | 是 | 所属一级大类ID |

**请求示例**

```json
{
  "name": "护肤品",
  "category_id": 1
}
```

**返回示例**

```json
{
  "id": 5,
  "name": "护肤品",
  "category_id": 1
}
```

---

#### 更新产品类别

```
PUT /entity/categories/{id}
```

**请求体（JSON）**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | string | 是 | 新类别名称 |

**请求示例**

```json
{
  "name": "护肤品（更新）"
}
```

**返回示例**

```json
{
  "id": 5,
  "name": "护肤品（更新）",
  "category_id": 1
}
```

---

#### 删除产品类别

```
DELETE /entity/categories/{id}
```

**返回示例**

```json
{
  "success": true
}
```

**错误示例（存在产品使用该类别）**

```json
HTTP 409
{
  "code": "Conflict",
  "message": "无法删除类别，存在 12 个产品使用该类别。请先删除或转移产品后再删除此类别。"
}
```

## 二、实体管理接口

### 2.1 产品管理

---

#### 获取产品列表（三级）

```
GET /entity/products/level3
```

**请求参数（Query）**

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| page | integer | 否 | 1 | 页码 |
| pageSize | integer | 否 | 20 | 每页数量 |
| keyword | string | 否 | - | 产品名称关键词搜索 |
| categoryId | integer | 否 | - | 按二级产品类型ID筛选 |

**返回示例**

```json
{
  "items": [
    {
      "id": 1,
      "name": "美白面霜A",
      "categoryId": 5,
      "categoryName": "化妆品",
      "adverseReactionCount": 15,
      "allergenCount": 8,
      "createdAt": "2026-01-10T08:00:00",
      "updatedAt": "2026-03-28T10:30:00"
    },
    {
      "id": 2,
      "name": "防晒喷雾B",
      "categoryId": 5,
      "categoryName": "化妆品",
      "adverseReactionCount": 23,
      "allergenCount": 12,
      "createdAt": "2026-01-15T09:00:00",
      "updatedAt": "2026-03-27T14:20:00"
    }
  ],
  "total": 85,
  "page": 1,
  "pageSize": 20
}
```

---

#### 获取产品详情

```
GET /entity/products/{id}?level=3
```

**路径参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | integer | 是 | 产品ID |

**Query 参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| level | integer | 是 | 固定传 `3` |

**返回示例**

```json
{
  "id": 1,
  "name": "美白面霜A",
  "categoryId": 5,
  "categoryName": "化妆品",
  "createdAt": "2026-01-10T08:00:00",
  "updatedAt": "2026-03-28T10:30:00"
}
```

---

#### 新建产品

```
POST /entity/products
```

**请求体（JSON）**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | string | 是 | 产品名称，不能重复 |
| level | integer | 是 | 固定传 `3` |
| category_id | integer | 是 | 所属二级产品类型ID |

**请求示例**

```json
{
  "name": "美白面霜A",
  "level": 3,
  "category_id": 5
}
```

**返回示例**

```json
{
  "id": 101,
  "name": "美白面霜A",
  "category_id": 5
}
```

**错误示例（名称重复）**

```json
HTTP 409
{
  "code": "Conflict",
  "message": "product name already exists"
}
```

---

#### 更新产品

```
PUT /entity/products/{id}
```

**请求体（JSON）**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | string | 是 | 新产品名称 |
| level | integer | 是 | 固定传 `3` |

**请求示例**

```json
{
  "name": "美白面霜A（升级版）",
  "level": 3
}
```

**返回示例**

```json
{
  "id": 101,
  "name": "美白面霜A（升级版）",
  "level": 3,
  "category_id": 5
}
```

---

#### 删除产品

```
DELETE /entity/products/{id}?level=3
```

**Query 参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| level | integer | 是 | 固定传 `3` |

**返回示例**

```json
{
  "success": true
}
```

**错误示例（存在关联）**

```json
HTTP 409
{
  "code": "Conflict",
  "message": "无法删除产品，存在 3 个化学应激源关联关系。请先删除相关关系后再删除此产品。"
}
```

## 三、数据采集接口

### 3.1 创建采集任务

```
POST /collection/tasks
```

**请求体（JSON）**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| entityType | string | 是 | `product` / `allergen` / `symptom` |
| entityId | integer | 是 | 实体ID |
| keyword | string | 是 | 采集关键词（默认为实体名称） |
| sources | array | 是 | 数据来源数组，可选值：`news` / `complaints` |
| timeRange | string | 否 | `1month` / `3months` / `6months` / `1year`，默认 `3months` |
| maxCount | integer | 否 | 最大采集数量，默认 `100` |
| maxCountPerSource | integer | 否 | 单个来源最大数量，默认 `50` |

  "maxCountPerSource": 50
}

## 五、错误码说明

### 统一错误响应格式

```json
{
  "code": "错误码字符串",
  "message": "具体的错误描述信息"
}
```

### 错误码对照表

| HTTP 状态码 | code 字段 | 说明 | 常见场景 |
|------------|-----------|------|----------|
| 400 | `BadRequest` | 请求参数错误或缺失 | 必填字段为空、格式不正确、level 参数无效 |
| 404 | `NotFound` | 资源不存在 | ID 不存在 |
| 409 | `Conflict` | 数据冲突 | 名称重复、关联已存在、存在子关联无法删除 |
| 500 | `InternalError` | 服务器内部错误 | 数据库异常、第三方服务异常 |

### 典型错误示例

**400 - 参数缺失**
```json
HTTP/1.1 400 Bad Request
{
  "code": "BadRequest",
  "message": "name is required"
}
```

**404 - 资源不存在**
```json
HTTP/1.1 404 Not Found
{
  "code": "NotFound",
  "message": "allergen not found"
}
```

**409 - 名称重复**
```json
HTTP/1.1 409 Conflict
{
  "code": "Conflict",
  "message": "allergen name already exists"
}
```

**409 - 存在关联无法删除**
```json
HTTP/1.1 409 Conflict
{
  "code": "Conflict",
  "message": "无法删除化学应激源，存在 8 个产品关联关系。请先删除相关关系后再删除此化学应激源。"
}
```

**409 - 关联已存在**
```json
HTTP/1.1 409 Conflict
{
  "code": 409,
  "message": "该关联关系已存在"
}
```

**500 - 服务器错误**
```json
HTTP/1.1 500 Internal Server Error
{
  "code": "InternalError",
  "message": "服务器错误，请稍后重试"
}
```
